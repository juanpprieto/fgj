# fgj

The fgj agent skill. [`SKILL.md`](SKILL.md) is the text that the build puts into the
binary and that `fgj skill install` copies into a harness, at `skills/fgj/SKILL.md`.
Only `SKILL.md` ships; this README does not.

This directory does not hold per-verb guidance: help shows it from each verb's `notes`.
