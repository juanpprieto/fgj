# docs

Design and decision records for fgj. [`design.md`](design.md) is the settled design: the
problems for agents, the gaps in the Forgejo API and in the tools around it, the command
contract, and the decisions. [`uat.md`](uat.md) is the human harness check: a one-time
setup, then a no-prompt run in each harness for each pull request that adds or changes a
verb. [`board-creation-research.md`](board-creation-research.md) describes repository board
routes, permissions, templates and the proposed REST API.
[`public-checkout.md`](public-checkout.md) records local source preparation.
[`release.md`](release.md) describes build, staging and provenance requirements.
[`github-validation.md`](github-validation.md) describes hosted-run, contributor approval and merge-protection checks.
[`setup.md`](setup.md) owns additional user setup and installation alternatives.
Code and tests do not live here.
