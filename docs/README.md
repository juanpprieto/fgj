# docs

This directory owns user setup, the settled design and maintainer validation guides.
Code and tests do not live here.

## Start here

- [`native.md`](native.md): downloads, checksums, installation, platform limits, upgrades and removal.
- [`setup.md`](setup.md): harnesses, account bindings, web login and common setup problems.
- [`design.md`](design.md): the Forgejo gaps, command contract, risk model and decisions.

## Maintainer references

- [`uat.md`](uat.md): human harness setup and no-prompt proof for changed verbs.
- [`release.md`](release.md): native release controls and the separate npm staging path.
- [`github-validation.md`](github-validation.md): hosted checks, contributor approval and merge protection.
- [`public-checkout.md`](public-checkout.md): source preparation and export checks, not user installation.
- [`bun-license.md`](bun-license.md): pinned upstream runtime license information, not compliance approval.
- [`board-creation-research.md`](board-creation-research.md): board routes, permissions, templates and the proposed REST API.
